terminal快捷键

1. 🚀 光标移动（导航）

  • Ctrl + ←/→ ：按单词跳转（向左/向右移动一个单词）。
  • Ctrl + A ：跳到行首（光标移至当前行的最开头）。
  • Ctrl + E ：跳到行尾（光标移至当前行的最末尾。）。

2. ✂️ 删除与剪切（按范围）

（注：以下Ctrl+U和Ctrl+K在删除的同时会将内容存入剪切板，供后续粘贴）

  • Ctrl + U ：剪切光标左侧所有内容（从行首删到光标位置）。
  • Ctrl + K ：剪切光标右侧所有内容（从光标位置删到行尾）。
  • Ctrl + W ：剪切光标左侧的一个单词（删除光标前最近的单词）。
  • Alt + D ：剪切光标右侧的一个单词（从光标当前位置向右删除至该单词末尾，并存入剪切板）。

3. 📋 粘贴与恢复

  • Ctrl + Y ：粘贴（将刚才用Ctrl+U、Ctrl+K或Alt+D剪切的内容粘贴出来）。

4. 🖥️ 屏幕与界面

  • Ctrl + L ：清屏（在终端中使用，相当于清空当前屏幕内容，通常保留当前命令）。
  • A = Ahead（前） → 行首；E = End（尾） → 行尾。
  • U = 光标左侧（想象左边那一坨）；K = 光标右侧（Kill，干掉右边）。
  • W = Word（单词），删除单词；Y = Yank（粘贴/拉回）。
